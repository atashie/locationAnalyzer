Can MapLibre GL JS 5.24.0 colour-map an arbitrary raster natively?

No for a plain raster layer. The style spec's raster paint properties on this version are raster-opacity, raster-hue-rotate, raster-brightness-min/max, raster-saturation, raster-contrast, raster-resampling / resampling, raster-fade-duration. There is no raster-color (Mapbox GL JS v3 has one); MapLibre tracks the request in issue #4479 (open).

Partial yes via color-relief. MapLibre added a color-relief layer type in 5.6.0 (changelog PR #5742) that maps per-pixel elevation to colour with an ["elevation"] expression, but it requires a raster-dem source (encodings terrarium, mapbox, or custom with red/green/blue factors and base shift). A minutes grid would have to be re-encoded into RGB PNG tiles and declared as a DEM; it colours one layer, it cannot AND six. Sources: style spec, layers and @maplibre/maplibre-gl-style-spec 26.5.1 v8.json (sdk-support js 5.6.0).

Note: MapLibre GL JS 6.x (6.16.0 on 2026-11-03) is ESM-only (changelog 6.0.0: UMD bundles no longer published), so a no-build page pins the newest UMD release, 5.24.0. The style-spec facts above were checked against the current spec package, whose raster paint list is identical for 5.24.0 and 6.16.0 bundles (both contain color-relief, neither contains raster-color).

Coordinate transform used for polygons and the canvas

d3-contour grid space: cell (i, j) covers x ∈ [i, i+1], y ∈ [j, j+1], centre (i+0.5, j+0.5); on a 0/1 mask at threshold 0.5 the smoothed vertices fall on cell edges. Row 0 is the north edge, so lon = W + x·(E−W)/ncols, lat = N − y·(N−S)/nrows. The canvas source uses the same four corners [[W,N],[E,N],[E,S],[W,S]], so raster and polygon align by construction. Validation: closed rings, ≥ 4 vertices, finite, inside bounds, exterior CCW / holes CW (RFC 7946), and polygon area vs in-cell count × cell area.

How to run and measure
  1. cd v2 && uv run python spikes/g3-render/make_fixtures.py (synthetic fixtures) — or drop the real export into fixtures/.
  2. npx serve v2/spikes/g3-render from the repo root; open http://localhost:3000. On a phone over LAN: http://<this PC's LAN IP>:3000 (same Wi-Fi; allow the port through the Windows firewall).
  3. Desktop: Chrome DevTools → Network → disable cache + the 4G throttling preset → reload; read "first mask paint". Then drag sliders 20+ times (or press Auto-bench) and read the medians.
  4. Phone: reload twice (second load is warm cache), drag sliders, press Polygonize, copy the results row.
