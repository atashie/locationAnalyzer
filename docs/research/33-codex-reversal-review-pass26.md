**Yes: prevalence and impact measurement should precede the final A–D choice.** It need not precede naming provisional A as the comparison baseline. Measurement decides priority and acceptable consequences; it cannot prove a universal invariance claim or decide which attachment semantics users ought to receive.

The cheapest honest experiment is a paired, staged audit:

1. **Attachment first.** Pin the prepared walk graph, geometry, coordinates, caps, runtime and rule versions. Reuse a recorded random sample from each existing frame: initially 500 structure centroids and 500 independent within-cell points. Audit all 550 grocery coordinates too, including eligibility changes: a destination attachment change can affect many origins. Benchmark the first batch before choosing a larger sample or a census. An indexed query must enumerate every segment potentially inside the global-minimum-plus-band window; a nearest-record-only API is insufficient. Keep occurrence deduplication and cap order identical between variants.
2. **Retain separate counts.** Report multiple candidates, multiple distinct records, multiple occurrences on one record, within-record band survivors removed by revision 9, and candidate-set differences between A, revision 9 and D. These are different events. On the local segment sets, exact rational squared-distance checks can distinguish genuine ties from merely close residuals; keep this diagnostic separate from full B normalisation. Do not label an arbitrary floating-point “near-tie” window as exact-tie detection. Record denominators, residual gaps, statuses and timing. Add a small separate set of lawful subdivision transformations to test representation sensitivity; the untransformed graph alone cannot measure that.
3. **Route only where candidates or eligibility differ.** Use a scalable development comparator, not the exhaustive toy oracle. Cache shared routing work. If destination candidates change, every sampled origin is potentially affected, even when its own candidates agree. Compare paired seconds, objective-specific selections, exact threshold verdicts and actual whole-minute encoding/browser verdicts at the release limits. Report absolute changes, tails, maximum and false-inclusion direction separately; F2's exact ten-minute flip is not itself an encoded-minute flip. Retain timeouts/unresolved comparisons rather than counting them as agreement. Keep targeted transformation results separate from population estimates.

This begins with existing data and a small batch, not another certification apparatus. Time-box the attachment pilot to one developer day, including a routing-cost estimate; if route comparison is unavailable, publish the attachment result and explicitly leave verdict impact unknown. Do not substitute candidate frequency for that missing result. Conversely, equal complete candidate inputs with identical downstream computation need no repeated route solve.

With zero events in 1,000 random observations **per frame**, a conservative one-sided 95% upper bound is about 0.30%, not “a handful in 512,633.” A small pilot can identify a common problem, not establish extreme rarity. Keep frames separate. Census the cheap attachment stage if benchmarking supports it; a ground-area sample still does not count every affected location within each cell. Also report impact among displayed PASS results, where a low full-frame rate can conceal concentrated harm.

Before viewing results, allocate a small attachment-sensitivity budget within the existing product requirements; do not invent a new release tolerance from the data. Pick **A** if its consequential differences fit that budget and no repeatable harmful pattern emerges. Pick **B** if meaningful harm is attributable to exact-tie loss or lawful representation changes, representation independence remains required, and a bounded implementation meets the measured runtime budget. Pick **C** only if the within-record minimum has a demonstrated benefit over A, exact ties need preservation, and record dependence is expressly acceptable. Pick **D** only if extra band attachments produce harmful competing routes and the owner deliberately accepts losing across-road alternatives. “Thousands of candidates” alone selects none of these. Differences between conventions also do not identify truth: inspect consequential cases against legal access and usable grocery journeys.

**§12 needs an explicit scope amendment, not an implicit escape.** A named operation sequence does not logically require identical arithmetic implementations: different algorithms can preserve the specified observables. Nor does it ensure portable equivalence. Floating-point computation can have precise deterministic semantics, but this project has not supplied that portable contract. Adopting A without qualifying §12 would leave the promise unsupported.

Replace the development claim with:

> This comparator version defines an operational baseline on the identified input artifacts and supported runtime/platform. Freeze its candidate convention, implementation, numerical environment, configuration and saved operands/results. Requalification compares candidate membership, statuses, selections and decision predicates, alongside numeric differences; passing finite fixtures is evidence only over those checks. Cross-implementation equivalence over all admissible inputs is not claimed. A changed convention is a semantic version change; an unproved implementation change receives a new comparator version and affected measurements are rerun.

T3 can therefore be a frozen **versioned development comparator** and an immutable record of what an experiment used. Saved rows can reproduce a report without rerouting. Neither freezing nor report reproducibility certifies physical accuracy or universal implementation interchangeability. Keep the stronger equivalence ambition separate if it is ever needed.

**Decision procedure:** write one page naming the product decision, supported scope, required claims, sensitivity budget and time box; run the paired pilot; inspect consequential cases; choose the simplest convention supported by that evidence; version it and proceed to real recommendation checks. Reopen only for a measured budget breach, a reproducible consequential error, or a required scope change. A new synthetic witness updates the declared limitation unless it contradicts a retained claim. Do not convert success on the latest corpus into a property of the rule again.
